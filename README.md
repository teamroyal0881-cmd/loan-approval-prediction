# Loan Approval Prediction System Using Machine Learning

## Files
- `loan_approval_dataset.csv` - dataset
- `train_model.py` - trains and saves the ML model
- `app.py` - Streamlit user interface
- `requirements.txt` - Python libraries

## Run on Windows / VS Code

1. Install Python 3.
2. Open this project folder in VS Code.
3. Open Terminal in VS Code.
4. Install libraries:

   pip install -r requirements.txt

5. Train the model:

   python train_model.py

6. Start the application:

   streamlit run app.py

A browser window should open automatically.

## Project Flow
Dataset -> Data Cleaning -> Train/Test Split -> Preprocessing -> Random Forest -> Evaluation -> Prediction Interface

## Note
This is an educational machine-learning demonstration. It should not be used to make real lending decisions.
